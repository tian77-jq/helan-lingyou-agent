- `PARTIAL`（exit 3）：核心能力已复现，但 **Web 入口因当前解释器未装 `fastapi`/`uvicorn` 而未执行** —— 属真实覆盖缺口，给出修复命令 `pip install -r requirements-web.txt`。
- `FAIL`（exit 2）：出现 `exit 2` 步骤或预检**核心**阻塞项（Python 版本 / 工程文件完整性 / 语料库 / 共享业务核心 / 目录可写）。

可选参数：`--with-regression`（追加 40 例回归）、`--skip-web`（显式跳过副本内 Web 服务）、`--keep`（保留临时目录供人工检查）。证据：`evidence/acceptance/clean_copy_report_*.json`。

|-------|--------------|------|
