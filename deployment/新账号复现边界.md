## 3. 账号级配置：给人工步骤，不伪称随源码迁移

以下三项**必须由评委在自己的账号中完成**，本仓库只提供接入件与操作步骤，不提供"已完成"结论：

1. **添加本地 MCP Server**：WorkBuddy 客户端 → 添加 `mcp-adapter/server.py`（stdio/JSON-RPC 2.0）。
   工具权限由**平台统一分配**，开发者不能在专家定义文件里自行添加系统工具。
2. **安装 / 更新专家团**：`/plugin update helan-lingyou-ningxia@my-experts`，或在插件管理页操作。
   **必须新建会话**——旧会话继续引用旧版本缓存目录，不会自动切换。
3. **（可选）配置凭证**：`HELAN_LLM_*` 模型端点、`HELAN_PEXELS_API_KEY` / `HELAN_UNSPLASH_ACCESS_KEY` 图片来源。
   只进环境变量/`.env`，不下发前端；未配置时不发起请求并如实上报 `NEEDS_AUTH`。

**不随源码迁移的具体资产**（开发者账号已取得、评委账号默认没有）：

- 平台侧 MCP 信任记录（曾在开发者账号完成的授权动作）；
- 已安装专家团的市场源缓存与注册表记录；
- 任何历史会话上下文与云端任务（新账号不可见）。
