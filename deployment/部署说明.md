## 4. 重启恢复
- 进程为无状态内存会话（不落盘），重启后已有会话清空；行程结论由引擎确定性重算，可复现。
- 若需持久化，可在 `web/app.py` 将 `Session(persist_dir=...)` 打开（默认关闭，符合隐私要求）。
- 重启命令同 §2；建议用进程守护（如 `nohup` / 任务计划 / 容器）保证决赛现场稳定。

## 5. 网络中断 / 模型故障状态
- 天气（A4）调用 open-meteo 失败 → 引擎诚实降级、留痕、`degraded=True`，不阻断发布，前端标注「待核实」。
- 后端依赖本地引擎，无需外部模型 API 即可运行基础行程/文化能力；内容创作为模板生成，不受模型故障影响。
- 外部网络不可用时，仅实时天气降级，其余功能正常。

## 6. 公网访问（决赛演示）
- 本机服务器建议经稳定 HTTPS 入口暴露（反向代理 / 隧道），测试外部手机、其他电脑与不同网络。
